# WeatherApp 🌦️  

Um aplicativo de clima simples e intuitivo, desenvolvido para fornecer informações meteorológicas em tempo real. Projeto ideal para aprendizado de integração com APIs, utilizando JavaScript para desenvolvimento frontend. 

![Preview](https://via.placeholder.com/800x400?text=Preview+do+WeatherApp) *(Adicione uma imagem real do projeto aqui)*  

---

## Recursos Principais 
- **Dados em tempo real**: Temperatura, umidade, velocidade do vento e condições climáticas.  
- **Busca por localização**: Insira o nome de qualquer cidade ou região para obter dados.  
- **Design responsivo**: Funciona em dispositivos móveis, tablets e desktops.  
- **Ícones dinâmicos**: Visualizações gráficas adaptadas às condições climáticas (sol, nuvens, chuva).  
- **Suporte a geolocalização**: Opção para detectar automaticamente a localização do usuário.  

---

## Tecnologias Utilizadas 
- **Frontend**: HTML5, CSS3, JavaScript.  
- **API**: [OpenWeatherMap](https://openweathermap.org/) para dados meteorológicos, e [Unsplash](https://unsplash.com/) para as imagens 
- **Ferramentas de versionamento**: Git.  

---

## Como Executar o Projeto  

### Pré-requisitos  
- Node.js (v14.x ou superior).  
- Chave de API do OpenWeatherMap: [Registre-se aqui](https://openweathermap.org/api).  
- Abrir a página oferecida pelo próprio GitHub
